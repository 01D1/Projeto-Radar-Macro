_aggregate_ltm() contract (from RESEARCH.md Pattern 2 + Code Examples):
- Args: ticker: str, conn: sqlite3.Connection, is_bank: bool -> dict[str, float]
- FLOW_ITEMS (summed across 4 quarters): net_revenue, ebit, net_income, cfo, capex, depreciation_amortization_cfo, dividends_paid, nii_gross, loan_loss_provision, fee_income, total_financial_revenues, total_financial_expenses
- SNAPSHOT_ITEMS (latest reference_date wins): cash, short_term_debt, long_term_debt, total_equity, total_assets, loan_portfolio_gross
- Derived: ebitda = ebit + depreciation_amortization_cfo; fcf = cfo - abs(capex); gross_debt = short_term_debt + long_term_debt; net_debt = gross_debt - cash
- If fcf inputs absent (cfo or capex NULL): fcf = None (do NOT default to 0)
- If ebitda inputs absent: ebitda = None
- Returns dict with all keys; missing keys have None values (not 0)
- ltm_quarters_used: INTEGER 1-4 reflecting how many distinct reference_dates were found
