## Spacing Scale

Declared values — derived from measured padding values in app.py CSS block. All multiples of 4 except the documented exceptions below.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-text gaps, inline badge padding |
| sm | 8px | Expander summary padding top/bottom |
| md | 12px | Metric card padding, expander body top padding |
| lg | 16px | Default section gap between Streamlit widgets; expander body horizontal padding; expander summary horizontal padding |
| xl | 24px | Section breaks within a page |
| 2xl | 32px | Major section header-to-content gap |

Border radius:
- Standard containers (metric cards, expanders): **8px**
- Tab bar tab: **6px 6px 0 0**
- Metric card variant: **10px**

Exceptions: Nav button internal padding is **6px 10px** — preserved from existing `app.py` CSS verbatim to prevent nav breakage. This matches the pre-existing `[data-testid="stPageLink"] a` rule exactly and must not be rounded to the 8-point grid. No touch-target exceptions needed — desktop-only tool. Exception: `md` token = 12px — preserved from existing app.py CSS verbatim (metric card padding + expander body top padding values measured from app.py lines 16–135: `[data-testid="stMetric"]` padding 12px 14px and `details > div` padding 12px 14px). Non-multiple-of-standard-set value retained to prevent metric card and expander height reflow.

Source: app.py CSS block (extracted in pre-loaded context).

## Typography

Streamlit uses a system font stack (Inter via CDN). The CSS block in app.py declares size/weight overrides for specific elements. Body text uses Streamlit's default 14px / 0.875rem.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Label | 11px (0.68rem) | 400 (regular) | 1.4 | Metric labels above metric values (muted, `#475569`), timestamps, dim text |
| Subheading | 13px (0.82rem) | 700 (bold) | 1.3 | Expander header summaries, nav buttons, tab labels (uppercase, letter-spacing 0.3px); merges former 12.5px nav/tab size |
| Body | 14px (0.875rem) | 400 (regular) | 1.5 | Prose blocks (`st.markdown`), table cell text, input text, descriptions |
| Display | 21px (1.3rem) | 400 (regular) | 1.2 | `st.metric` large number display only |

Weights in use: **400 (regular)** and **700 (bold)** only.

PDF typography (fpdf2 / Helvetica):
| Role | Size | Style | Usage |
|------|------|-------|-------|
| PDF title | 14pt | Bold | Document header (`_header_section`) |
| PDF section heading | 11pt | Bold | Each section title |
| PDF body | 10pt | Regular | Prose text, bullet items |
| PDF table cell | 9pt | Regular | Drivers/risks tables, multiples table |
| PDF footer | 8pt | Italic | Page number + CVM disclaimer footer line |

Source: app.py CSS (pre-loaded context). PDF roles are Claude's discretion defaults — match fpdf2 Helvetica standard practice.

## Component Contracts

### Watchlist Page (`inteligencia_watchlist.py`)

Component: `st.dataframe` with Pandas `Styler.map()`

Column order and display:
| # | Column key | Display label | Notes |
|---|-----------|--------------|-------|
| 1 | `ticker` | Ticker | Left-aligned |
| 2 | `positioning` | Posicionamento | Color-coded via Styler (see semantic colors) |
| 3 | `confidence` | Confiança | Uppercase: ALTA / MEDIA / BAIXA |
| 4 | `fair_value_brl` | Valor Justo (R$) | 2 decimal places |
| 5 | `upside_pct` | Upside % | 1 decimal place, `+/-` prefix |
| 6 | `price` | Preço (R$) | 2 decimal places |
| 7 | `pe_ratio` | P/E | 1 decimal place |
| 8 | `ev_ebitda` | EV/EBITDA | 1 decimal place |
| 9 | `generated_at` | Tese Gerada em | ISO datetime truncated to minutes |

Sortable: `use_container_width=True`, `hide_index=True`.

Positioning color map (Pandas Styler):
```
"COMPRAR" → "background-color: #16a34a; color: white"
"MANTER"  → "background-color: #ca8a04; color: white"
"VENDER"  → "background-color: #dc2626; color: white"
```

Source: CONTEXT.md D-07, D-08; RESEARCH.md Pattern 5.

### Asset Detail Page (`inteligencia_ativo.py`)

Layout (top to bottom):
1. Ticker selector: `st.selectbox` — label "Selecionar ativo:"
2. Positioning metric: `st.metric(label="Posicionamento", value=positioning)` — colored via `st.markdown` HTML badge overlay or `delta_color` workaround
3. Fair value + upside: `st.columns(2)` — left: `st.metric("Valor Justo (R$)", fair_value)`, right: `st.metric("Upside", f"{upside:+.1f}%")`
4. Bull case: `st.subheader("Cenário Otimista")` then `st.markdown(bull_case_prose)`
5. Bear case: `st.subheader("Cenário Pessimista")` then `st.markdown(bear_case_prose)`
6. Drivers: loop `st.expander(f"Driver: {title}")` — body = description + impact badge; expander summary padding `8px 16px`
7. Risks: loop `st.expander(f"Risco: {title}")` — body = description + severity badge; expander summary padding `8px 16px`
8. Download button: `st.download_button(label="Baixar Relatório PDF", data=pdf_bytes, file_name=f"relatorio_{ticker}.pdf", mime="application/pdf")`

Impact / severity badge colors:
- HIGH → `background-color: #dc2626; color: white; padding: 2px 8px; border-radius: 4px`
- MEDIUM → `background-color: #ca8a04; color: white; padding: 2px 8px; border-radius: 4px`
- LOW → `background-color: #16a34a; color: white; padding: 2px 8px; border-radius: 4px`

Source: CONTEXT.md D-09, D-17.

### Opportunities Page (`inteligencia_oportunidades.py`)

Each signal card (10 total, ranked by conviction score DESC):
```
st.columns([1, 3, 1, 2])
  col1: st.markdown(ticker badge)
  col2: signal description (st.write)
  col3: signal_type badge
  col4: st.progress(conviction_score / 100, text=f"{conviction_score}/100")
```

Signal type badge colors:
- `DCF_DIVERGENCE` → `background-color: #3B82F6; color: white` (accent blue — included in accent Reserved-For list)
- `MOMENTUM_CROSSOVER` → `background-color: #ca8a04; color: white` (hold amber)
- `IPE_EVENT` → `background-color: #1E3A5F; color: #93C5FD` (tag highlight + accent text)

`st.progress()` bar uses Streamlit default blue (no override) with `text` parameter for score label.

Source: CONTEXT.md D-10; Claude's discretion for signal type badge colors.

### Macro Panel (`inteligencia_macro.py`)

One `st.plotly_chart` per series, in a 2-column layout: `st.columns(2)` for each pair, last series in full width.

Series order: Selic, IPCA_12m, PTAX, CDS Brasil, PIB Nominal.

Plotly layout for every chart:
```python
fig.update_layout(
    template="plotly_dark",
    paper_bgcolor="rgba(0,0,0,0)",       # transparent — blends with #0A0E1A
    plot_bgcolor="rgba(13,20,33,1)",      # #0D1421
    font=dict(color="#94A3B8"),           # text muted
    xaxis=dict(gridcolor="#1E2D42", showgrid=True),   # border color for gridlines
    yaxis=dict(gridcolor="#1E2D42", showgrid=True),
    margin=dict(l=10, r=10, t=30, b=10),
    height=280,
    showlegend=False,
)
```

Line color for each series trace: `#93C5FD` (accent text — consistent, single-series charts).

Chart titles (passed via `fig.update_layout(title=...)`):
- Selic Over → "Selic (% a.a.)"
- IPCA_12m → "IPCA Acumulado 12m (%)"
- PTAX → "PTAX (R$/USD)"
- CDS Brasil → "CDS Brasil (bps)"
- PIB Nominal → "PIB Nominal (R$ bi)"

Source: CONTEXT.md D-11; RESEARCH.md Pattern 6; Claude's discretion for gridline color and series color.

## PDF Report Contract

Section order (fpdf2 page flow):

| # | Section method | Content |
|---|---------------|---------|
| 1 | `_header_section(ticker, generated_at)` | Document title, ticker, generation date |
| 2 | `_thesis_section(thesis)` | Positioning badge, confidence, rationale, summary_one_line |
| 3 | `_bull_bear_section(thesis)` | Bull case prose, bear case prose (2 sub-sections) |
| 4 | `_drivers_risks_section(drivers, risks)` | fpdf2 `table()` context manager — columns: title, description, impact |
| 5 | `_valuation_section(dcf, multiples)` | Fair value BRL, upside %, P/E, EV/EBITDA, P/BV, dividend yield |
| 6 | `_financials_section(ltm)` | LTM: revenue, EBITDA, net income, FCF, net debt — all in R$ milhões |
| 7 | `_macro_section(macro)` | Selic, IPCA 12m, PTAX, CDS Brasil — text table, no embedded chart |
| 8 | `_disclaimer()` | CVM IN 598 text — always last, always present |

Page margins: left 20mm, right 20mm, top 25mm, bottom 20mm (fpdf2 defaults with slight top increase for header).

CVM IN 598 disclaimer text (exact wording — hardcoded, never truncated):

> "Este relatório foi elaborado por analista de valores mobiliários autônomo, em conformidade com as disposições da Instrução CVM nº 598, de 3 de maio de 2018. As informações e análises contidas neste documento têm caráter exclusivamente informativo e não constituem oferta de compra ou venda de valores mobiliários, tampouco recomendação de investimento. O analista responsável certifica que as opiniões expressas neste relatório refletem de forma precisa, exclusiva e independente suas visões e análises pessoais. Investimentos em valores mobiliários envolvem riscos. Rentabilidade passada não é garantia de rentabilidade futura."

## State Contracts

### Empty States

| Page | Trigger | Component | Copy |
|------|---------|-----------|------|

Source: CONTEXT.md D-06; Claude's discretion for per-page empty state copy.

### Loading States

Streamlit shows a native spinner on `@st.cache_data` miss. No additional spinner needed. TTL=300s means cold loads trigger data fetch; subsequent loads within 5 minutes use cache silently.

### Error States

Use `st.error()` for exceptions in data loading (caught in page file with `try/except`). Never expose raw tracebacks to the user.
